# Calendar Verification

The desktop calendar renders the Paper Field Notes layout with the asymmetric semester rail, month controls, interactive calendar grid, event legend, and selected-day agenda margin. The review refinement is visible: active months and selected dates use paper tints, rules, and terracotta markers instead of filled dark blocks, while the agenda header uses ruled-paper calendar tabs rather than a lifestyle image.

The mobile calendar renders as a narrow single-column flow at 375 × 812 pixels. It retains the month jump controls, tappable date grid, event markers, selected-day details, and monthly event list without visible clipping. Type, date cells, and event spacing remain readable at the mobile breakpoint.
